# AgentOps AI v0.3 — Tool Calling + MCP Integration

## Реализовано

Единый Tool Registry объединяет встроенные инструменты и discovery собственного MCP-сервера. У каждого инструмента есть стабильный ID, описание, JSON Schema, read-only/write, таймаут, лимит вызовов, размер ответа, источник и статус. Агент выбирает разрешения в своей форме; snapshot сохраняет их на запуск. Gemini получает только разрешённые function declarations через официальный google-genai (`parameters_json_schema`), automatic function calling и скрытые SDK retries отключены.

Общий асинхронный Tool Executor обслуживает Single-Agent и Multi-Agent: проверяет активность запуска, разрешение, строгие Pydantic параметры, лимиты, выполняет реальную функцию и сохраняет маскированную историю в SQLite. Ответ передаётся модели как `untrusted_tool_data` с явным запретом следовать инструкциям из результата. Недоверенные результаты не могут расширить серверные разрешения.

| ID | Поведение |
|---|---|
| calculator | Ограниченная арифметика через AST; без eval, степеней, функций или произвольного кода |
| utc_time | Совместимый с MVP UTC clock |
| datetime | UTC now, ISO add_days и difference_days; даты без timezone считаются UTC |
| json_validator | Реальный parse и JSON Schema validation; ограниченный безопасный subset, без внешних refs, regex и combinators |
| http_fetch | GET только точного HTTPS URL из серверной конфигурации; публичные IP, проверка каждого redirect, закреплённый адрес и TLS hostname |
| knowledge_search | Поиск по двум явно перечисленным тестовым документам приложения, без произвольных путей |
| mcp_local_time | Реальный read-only вызов времени через локальный MCP |
| mcp_knowledge_search | Реальный read-only поиск через локальный MCP |
| save_note | Добавляет заметку в SQLite приложения только после human approval |

Knowledge Search — ограниченный lexical search по test fixtures, без RAG, embeddings и интернет-поиска. HTTP Fetch действительно обращается к сети, но только к настроенному точному URL; по умолчанию это https://example.com/.

## MCP

Работает собственный сервер `app/local_mcp_server.py` и stdio JSON-RPC client. Зафиксирована совместимая ревизия **2025-11-25**: initialize → notifications/initialized → tools/list → tools/call. Discovery проверяет точный набор имён и совпадение схем с доверенными локальными контрактами, после чего импортирует MCP tools в Registry. Неизвестные инструменты не регистрируются.

Запускается исключительно текущий Python с фиксированным собственным файлом, без shell и команд из пользовательского ввода. Из окружения subprocess исключены Gemini key, API token и PYTHONPATH. Подключение иных executable, URL и сторонних серверов отсутствует. Транспорт проверяет ID ответа, версию, размеры и timeout; при отключении вызов завершается ошибкой. Автоматического переподключения/повтора вызова нет. Через UI можно явно повторить discovery собственного сервера.

Это минимальный MCP tools client/server для фиксированного stdio сервера, а не универсальная реализация всех MCP capabilities. Remote HTTP MCP, resources/prompts, server subscriptions, OAuth и новая stateless ревизия остаются roadmap. [Протокол tools](https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/docs/specification/2025-11-25/server/tools.mdx).

## Подтверждения и защита от повтора

Write tool разрешение агента само по себе не разрешает выполнение. `save_note` создаёт tool_call в awaiting_approval; интерфейс показывает действие и неизменяемые маскированные параметры. Approve / Reject сохраняется сервером с атомарной проверкой текущего состояния. Повторное решение получает HTTP 409.

До Approve заметка отсутствует. После Approve запись note, уникальный call_id и completed результат сохраняются в одной транзакции. Ключ идемпотентности write — тип/ID запуска + ID инструмента + SHA-256 канонических аргументов. Повтор того же действия в одном запуске, включая Reviewer retry, возвращает сохранённый результат без новой записи. Новый запуск — новый контекст подтверждения. Изменённые параметры — новое действие, требующее отдельного Approve.

Reject завершает вызов и запуск явной ошибкой tool_rejected. Таймаут ожидания — 60 секунд по умолчанию. Отмена и перезапуск не продолжают pending writes; состояние и длительность сохраняются. Очередь сейчас последовательная: ожидание подтверждения занимает worker. Существующий общий таймаут выполнения продолжает действовать.

## Хранение, API и UI

Миграция 003 добавляет `tool_calls` и `tool_notes`, не изменяя старые таблицы. История содержит маскированные параметры и результат, статус, ошибку, длительность, decision и время решения; workflow call связан с конкретной попыткой stage_id. Parent execution/workflow events фиксируют tool_requested/completed/failed/cancelled/reused и approval события.

API: `/api/tools`, `/api/mcp-servers`, `POST /api/mcp-servers/local-readonly/discover`, `/api/tool-calls?run_kind=single|workflow&run_id=...`, `POST /api/tool-calls/{id}/decision`. Применяются прежние bearer-защита и same-origin frontend proxy. Произвольного HTTP endpoint для запуска любого инструмента нет: вызовы проходят через разрешённый агентный запуск.

Tools показывает каталог, схемы, разрешённых агентов, access, источники, статусы, лимиты, HTTP allowlist и MCP сервер. В Single-Agent и workflows добавлены Tool History с результатами и Approve/Reject. Все новые строки централизованы в tool-i18n.ts (RU/EN).

## Ограничения безопасности

Лимит — 4 вызова каждого инструмента и 32 разных вызова на запуск, не более 8 tool requests в одном ответе модели; действуют существующие model-call/token/timeout бюджеты. Ответ ≤16 KiB; аргументы ≤20 KB. MCP RPC timeout 5 секунд, HTTP Tool timeout 10 секунд, сетевой socket/abort budget 8 секунд. JSON Validator ограничивает размер документа и схемы, запрещает remote refs, regex и комбинаторы, чтобы избежать сетевого доступа и вычислительных атак.

SSRF: точные URL, HTTPS/443, без credentials/fragments/proxies; проверяются все DNS адреса, запрещены private/loopback/link-local/reserved/shared/multicast, включая IPv4-mapped IPv6. TCP соединение использует один проверенный IP, TLS проверяет исходное имя. Redirect должен снова проходить exact allowlist и DNS; максимум три перехода. Сжатые/бинарные ответы запрещены. Для HTTP данных HTML не исполняется — UI выводит plain text.

DNS использует ОС и отдельный thread: timeout прекращает ожидание запуска, но системный DNS resolver может завершиться позже. Это остаточное ограничение локальной реализации. Нет гарантии полного удаления всех возможных секретов: маскируются известные ключи/токены, секретные поля и характерные текстовые шаблоны. Входные задачи, инструкции, model raw outputs и checkpoints по-прежнему локально хранятся без шифрования; не передавайте туда секреты. Prompt injection ограничивается серверной политикой и permissions, а не гарантией корректного ответа модели.

Нет инструментов shell/Python execution, произвольного чтения файлов, произвольных URL или внешних write-действий. Exactly-once защита реализована для собственной SQLite note; перенос на внешние side effects потребует их idempotency API/outbox. RBAC, distributed workers, tenant isolation и внешние write integrations остаются roadmap.

## Проверки

Автоматические тесты используют Mock LLM, но Calculator, дата, JSON, поиск и MCP исполняют реальные локальные функции. Mock никогда не включается как fallback Gemini. Маркер `[MOCK_TOOL:calculator] {"expression":"(10+2)/3"}` задаёт явный offline test scenario, после которого Mock получает настоящий function_response. Multi-Agent Mock также сохраняет tool_results в передаваемый JSON artifact.

- Backend regression и v0.3 security tests: строгие аргументы, forbidden tool, math failure, timeouts, SSRF/DNS/redirect/size, SDK declarations, MCP discovery/call/disconnect, Approve/Reject, pending cancellation/restart, call limits и write replay; Single-Agent и Multi-Agent.
- Frontend unit RU/EN, TypeScript и production build.
- Playwright: Calculator = 4, MCP search, Approve/Reject в UI, history после reload, RU/EN, прежний workflow, Single-Agent, mobile и proxy origin.
- Отдельная локальная проверка с временной SQLite: Calculator = 4; MCP search возвращает portal.md; Approved note saved=true; Reject без записи; реальный HTTP Fetch https://example.com/ → HTTP 200, 577 байт.

[Полная трассировка локальных примеров](v03-tool-examples.json). В тестовой базе нет пользовательских данных. Реальных Gemini-запросов в v0.3 не выполнялось; живой Gemini Function Calling для новых инструментов потребует отдельного разрешения. Native SDK configuration проверена с mocked transport.
